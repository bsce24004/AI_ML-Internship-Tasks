## Task 1: Iris Dataset Exploration

### Objective
The goal of this task is to explore and visualize the Iris dataset to understand patterns and relationships between features.

### Dataset
Iris dataset (loaded using seaborn)

### Work Done
- Data loading using pandas and seaborn
- Data exploration (shape, info, describe)
- Data visualization:
  - Scatter plot
  - Histogram
  - Box plot

### Key Findings
- Setosa has the smallest petal length
- Virginica has the largest values
- No missing data found
- Species are clearly separable in plots
