# Task 6 - House Price Prediction

## Objective
To predict house prices using machine learning based on features like size, bedrooms, and location.

---

## Dataset
Since no dataset was provided, a synthetic dataset was generated using NumPy and Pandas.

Features:
- Square Footage (sqft)
- Bedrooms
- Location (A, B, C)

Target:
- House Price

---

## Methodology
1. Synthetic dataset creation
2. Label encoding for categorical data
3. Train-test split
4. Linear Regression model training
5. Predictions
6. Model evaluation
7. Visualization

---

## Model Used
- Linear Regression

---

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

---

## Results
- Model successfully learned relationship between features and price
- Low error indicates good prediction performance
- Visualization shows comparison of actual vs predicted values

---

## Skills Learned
- Regression modeling
- Synthetic dataset creation
- Feature engineering
- Model evaluation
- Data visualization
