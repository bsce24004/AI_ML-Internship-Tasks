# AI/ML Internship Task 2 - Stock Price Prediction

## 📌 Objective
The objective of this project is to predict the next day's stock closing price using historical stock market data and machine learning techniques.

---

## 📊 Dataset
- Source: Yahoo Finance
- Library Used: yfinance
- Stock Used: Apple Inc. (AAPL)

The dataset contains:
- Open Price
- High Price
- Low Price
- Close Price
- Volume

---

## 🛠 Technologies and Libraries Used
- Python
- Pandas
- yfinance
- Matplotlib
- Scikit-learn

---

## 🤖 Machine Learning Model
Model Used:
- Linear Regression

The model was trained using:
- Open
- High
- Low
- Volume

to predict:
- Next Day Closing Price

---

## 📈 Project Workflow
1. Load historical stock data using yfinance
2. Explore and inspect the dataset
3. Create target column using next day's closing price
4. Select features and target variables
5. Split dataset into training and testing sets
6. Train Linear Regression model
7. Predict stock prices
8. Visualize Actual vs Predicted prices

---

## 📊 Results
- The model successfully learned patterns from historical stock data.
- Predicted prices followed the general trend of actual prices.
- The project demonstrated the basics of regression modeling and time-series prediction.

---

## 📷 Output Visualization
The project includes a graph comparing:
- Actual Stock Prices
- Predicted Stock Prices
